AI & Agents · Featured2026

AI Agent Harness

An LLM agent and the harness around it, built from scratch. It runs real tools safely, survives long sessions and remembers what it learned.

Task→ReAct loop→Tool registry→Docker sandbox↺Compaction + RAG memory
PythonOpenAI APIDockerChromaDB
  • Built a ReAct agent loop with pluggable tools (bash, filesystem, git, web search) and step budgets that stop runaway loops.
  • Sandboxed every agent-run command in auto-provisioned Docker containers, isolating LLM-generated code from the host.
  • Implemented context compaction with auto-summarization and disk offload to keep long sessions within token limits.
  • Added self-updating project memory (AGENTS.md) and a RAG pipeline over OpenAI embeddings and ChromaDB.
